# Creating and Order Panel

To create and order set first order at least 2 different orders. E.g. start with **'Full Blood Count'** and then add **'Renal Profile'**

Select thee **'Options'** on the bottom right and **'Create Panel'**. You can name this panel and add on further Orders.

This is useful for creating commonly ordered tests or drugs e.g. Daily bloods or commonly prescribed medications
