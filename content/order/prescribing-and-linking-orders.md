# Prescribing and adjusting Medication orders

To prescribe medication:

1. select **'Add Order'** and search up the required drug
2. Review and ammend the prescription details as required, including:
   - Dose
   - Route
   - Frequency
3. Select the start date and time
4. Set the duration if appropriate (if left blank it will continue indefinately)
   Adjust the first dose if needs to be given at a specific time
5. Review and, if required, modify the scheduled administration times to ensure the medication is given at the appropriate times.

## Linking Orders

Linking orders is useful for either:

- providing an alternative route of administatraion for the same medication (e.g. oral OR IV)
- Creating a weaning/tapering plan where one prescription follows another

1. Select **'Link Order'**
2. If you're creating a weaning plan or follow up medication select **'Followed by'** (you will need to add a duration on the first drug)
   - select **'Copy of current order'**
   - Reduce the dose and choose a duration
   - Continue linking orders until weaning plan is complete

3. If you're providing alternative administration routes for a medication select **'Or'**
4. Search up the medication using an alternative route
5. Complete the prescription details (dose, route, frequency, and any other required information) before saving the linked order.
